# 介绍

**Orbien** 是一款基于 **Rust** 语言开发的高性能内网穿透工具，能够将位于内网的服务安全、高效地暴露到公网，供外部用户访问。它通过建立稳定的反向隧道，
突破**防火墙**的限制，适用于**远程调试**、**内网服务公开**、**开发测试**、**物联网设备**接入等多种场景。

## 功能特性

- **多协议代理**：支持 TCP、UDP、HTTP、HTTPS 协议
- **传输层** 支持TCP、QUIC、KCP、WebSocket多种传输协议可选
- **多路复用**：支持TCP多路复用，一条物理连接承载多条逻辑工作流，降低开销和延迟
- **HTTPS** HTTPS 按 SNI 透传，域名证书在本地，可选客户端TLS终止
- **安全** ：支持 TLS 与 mTLS加密传输，保证数据安全性
- **运维**：提供轻量服务端Web界面和跨平台桌面客户端，方便运维监控
- **跨平台**：支持 Linux、Windows、macOS、FreeBSD 多架构
